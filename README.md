# Instagram AI 投稿生成エンジン

Instagramのリール投稿（リスト・ランキング・チェックリスト形式）を、Claude CodeでHTML/CSS→PNG生成し、背景動画に合成するところまで半自動化する一式です。

導入・運用の詳しい考え方は [`CLAUDE.md`](./CLAUDE.md) を参照してください。このREADMEは最初の一歩だけを扱います。

## 必要なもの（事前準備・別途お渡しする案内動画を参照）

- **Claude Codeが使える状態**（WSL/ターミナルの用意、Anthropicのサブスク or APIキー契約、Claude Codeのインストールまで完了していること）
- **VS Code**（フォルダを選ぶのに使う。インストールしていなければ https://code.visualstudio.com/ から）
- **git**（`git --version`で確認できればOK。大抵は最初から入っています）

ここまでは案内動画の手順どおりに進めてください。この先（Node.js・Python・画像生成に必要なブラウザ(Chromium)のインストール）は、Claude Code自身が対話しながら進めるので、事前に何かを入れておく必要はありません。

## はじめかた

**ターミナルにコマンドを打つのではなく、エクスプローラーとVS Codeの操作だけで場所を決めます。** こうすることで「クローンしたファイルがどこにあるか分からない」を避けられます。

1. エクスプローラーで、好きな場所（デスクトップでもどこでもよい）に新しいフォルダを作る（右クリック→新規作成→フォルダ。名前は何でもいい。例: `Instagram-AI`）
2. VS Codeを開き、「フォルダを開く」でそのフォルダを選ぶ
3. VS Code内のターミナルを開く（メニューの「表示」→「ターミナル」）
4. そこで次のコマンドを打つ（末尾の`.`を忘れずに。「今開いているこのフォルダの中に展開して」という意味）

```bash
git clone https://github.com/tutoloop/Instagram-AI.git .
```

これで、**自分がさっき作ったフォルダの中**にファイル一式ができる。自分で作った場所なので、「どこにあるか分からない」が起きない。

続けて、同じVS Code内のターミナルでClaude Codeを起動し、次のどちらかを入力してください。

```
/setup
```

または単に「セットアップして」と話しかけてください。ランタイムのインストールから、アカウント名・ジャンルの設定、最初の1本を作るところまで、Claudeが対話形式で案内します。**コマンドを自分で調べたり打ったりする必要はありません**。返事や、Pexels APIキー（無料。案内が出たタイミングで https://www.pexels.com/api/ から取得）の入力だけお願いします。
