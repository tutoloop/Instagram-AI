# 分析/

Meta Business Suiteからエクスポートしたインサイトデータの傾向分析。任意モジュール（Instagram/Facebookのログイン情報を扱うため、導入時にセットアップが1段重くなる。**スキップしても他のモジュールには影響しない**）。

## ログイン情報について（任意）

`/setup`のヒアリングで「今は使わない」を選んだ場合、このフォルダに`.env`は作られません。後で使いたくなったら:

```bash
cp 分析/.env.example 分析/.env
# .env を開いて FB_EMAIL / FB_PASSWORD を書く
```

`.env`は`.gitignore`済みなので、書いた内容がコミットされたりGitHubに上がったりすることはありません。**この情報はブラウザでMeta Business Suiteにログインしてインサイトをエクスポートする作業に使うもので、購入したPCの外には出ません。**

現状、ログインから自動でCSVを落とすスクリプトはこのリポジトリに同梱していません（Claude Codeがブラウザ操作ツールを使える環境であれば、`.env`の情報を使ってログイン→エクスポートまで対話的に頼めます。ツールが無い環境では、Meta Business Suiteに手動でログインしてCSVをエクスポートしてください）。

## 使い方

1. Meta Business Suite（またはInstagramプロフェッショナルダッシュボード）からインサイトCSVをエクスポートし、`insights_<開始日>_<終了日>.csv`のような名前でこのフォルダに置く
2. `python3 analyze_insights.py` … 投稿ごとの傾向（保存率・シェア率・フォロー率など）を出力
3. `python3 age_by_post.py` … 投稿ごとの視聴者年齢層を出力

## 分析結果の使い道

分析結果は`テキスト画像生成/` `ノート画像生成/` `Tier表/`の各CLAUDE.mdにある「型」「デザイン」「ネタの切り口」の判断材料にフィードバックする。伸びたデザイン・ネタの傾向は、自分のジャンル用のメモとして書き足していくことを推奨する（例: `分析/notes.md`を自分で作る）。

CSVそのもの（実際のインサイトデータ）はこのリポジトリに含めない。個人のアカウントデータなので、エクスポートしたら`.gitignore`済みのこのフォルダに置くだけで、コミットされない。
