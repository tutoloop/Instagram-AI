# 学習/

使うほどあなたのアカウント専用に育っていく仕組みの置き場です。

## フィードバック.md

あなたがClaudeに出した指摘・修正・好みを溜めていくログです。`/setup`のときに`フィードバック.md.example`から`フィードバック.md`が作られます。以降、Claudeは投稿を作る前に必ずこのファイルを読み、指摘に沿った提案をします。修正を出すたびに、Claudeが自動でここに追記していきます（自分で書き足しても構いません）。

## 参考アカウント/

「この投稿みたいな感じで作って」と言いたいとき、参考にしたい投稿のスクリーンショットをここに置いてください。Claudeに「この中の投稿を分析して」と頼むと、デザイン・コピーのパターンを言語化して`フィードバック.md`に書き足します（画像そのものはコピーの参考にするだけで、真似して丸ごと再現することはしません）。

このフォルダの中身（他者のアカウントのスクリーンショット）は`.gitignore`済みです。他者の投稿画像を保存する場所なので、外部に共有・配布しないでください。
